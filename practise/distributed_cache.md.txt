# Problem

A distributed cache is a system that stores data as key-value pairs in memory across
multiple machines in a network. Unlike single-node caches that are limited by the
resources of one machine, distributed caches scale horizontally across many nodes to
handle massive workloads. The cache cluster works together to partition and replicate
data, ensuring high availability and fault tolerance when individual nodes fails

# Assumptions
1. Read dominated (which is why we want different reads to go to different nodes to distribute the load)
2. TTL must be enforced for each key, i.e., evict keys more than TTL seconds old.
3. If the distributed space is full, evict the Least Recently Used Key.
