## LC 567 — Permutation in String (Medium) ✓

**Pattern**: Fixed sliding window

**Key insight**: Slide = remove left char + add right char. O(1) update.
Pop zero-count entries so the map stays clean — avoids spurious matches on key set comparison.

**Apple interview failure mode**: Was rebuilding the entire hashmap each iteration → O(n·k) brute force. The fix: ask "what is the difference between the old window and the new window?" For any fixed window, exactly two characters change.

**Canonical form**:
```python
s1_count = Counter(s1)
window = Counter(s2[:len(s1)])
if window == s1_count:
    return True
for i in range(len(s1), len(s2)):
    window[s2[i]] += 1
    left = s2[i - len(s1)]
    window[left] -= 1
    if window[left] == 0:
        del window[left]
    if window == s1_count:
        return True
return False
```

## LC 102 — Binary Tree Level Order Traversal (Medium) ✓

**Pattern**: BFS on tree, `len(q)` snapshot

**Key insight**: `len(q)` at the start of each iteration = exactly the number of nodes at the current level. Process exactly that many, then everything remaining is the next level.

**Canonical form**:
```python
result = []
q = deque([root])
while q:
    level_size = len(q)
    level = []
    for _ in range(level_size):
        node = q.popleft()
        level.append(node.val)
        if node.left:  q.append(node.left)
        if node.right: q.append(node.right)
    result.append(level)
return result
```

**Variants** (same pattern, one line change):
- Right side view → `level[-1]`
- Level averages → `sum(level) / len(level)`
- Zigzag → reverse `level` on odd depths

## LC 322 — Coin Change (Medium) ✗ TLE on 2D with k-loop

**Pattern**: Unbounded knapsack → 1D DP

**Recurrence derived**:
```
DP[c, a] = min over k in {0, ..., floor(a/v)} of (DP[c-1, a - k*v] + k)
```
k=0 = skip coin c. Correct and derivable from first principles.

**Why k-loop TLEs**: O(n × amount² / min_coin). For amount=10000, coin=1 → 10^8+ ops.

**Collapse to O(n × amount)**:
`DP[c, a-v] + 1` equals the tail of the sum (shift k by 1, add 1). So:
```
DP[c][a] = min(DP[c-1][a], DP[c][a-v] + 1)
```
Same row on the right = coin still available = unbounded reuse.

**1D template** (memorize this):
```python
dp = [0] + [float('inf')] * amount
for coin in coins:
    for a in range(coin, amount + 1):
        dp[a] = min(dp[a], dp[a - coin] + 1)
return dp[amount] if dp[amount] != float('inf') else -1
```

**Key distinction**:
- 2D natural for 0/1 knapsack (items consumed, row tracks remaining items)
- 1D natural for unbounded (pool never shrinks, no dimension needed)

## LC 141/142 — Linked List Cycle (Easy/Medium) ✓ (traced by hand)

**Pattern**: Slow/fast pointer (Floyd's algorithm)

**Phase 1 — detect**:
```python
slow, fast = head, head
while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
    if slow == fast:
        break  # cycle exists
```

**Phase 2 — find entry** (LC 142):
Reset one pointer to head, walk both at speed 1, they meet at cycle entry.
```python
slow = head
while slow != fast:
    slow = slow.next
    fast = fast.next
return slow
```

**Trace example**: 1→2→3→4→2 (cycle at 2)
- Meet at node 4 (phase 1)
- Reset slow to head=1, walk: (1,4)→(2,2) — meet at node 2 ✓

## LC 206 — Reverse Linked List (Easy) ✓ (with fix)

**Pattern**: Three pointer dance (prev/curr/next)

**Bug in first attempt**: Loop condition `while r is not None` exits before processing the last node.
Fix: add `c.next = l` after the loop to handle the last node.

```python
if not head:
    return None
l, c, r = None, head, head.next
while r is not None:
    rn = r.next
    c.next = l
    l, c, r = c, r, rn
c.next = l  # process last node
return c
```
