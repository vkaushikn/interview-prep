## Problems Covered

### LC 981 — Time-Based Key-Value Store
- Store: `defaultdict(list)` of `(timestamp, value)` tuples — guaranteed increasing timestamps on set
- Get: binary search for largest timestamp ≤ query (floor variant)
- Floor binary search: record candidate when `lst[mid][0] <= ts`, go right (`lo = mid + 1`). Return `""` if nothing qualifies.
- Ceiling variant (smallest ≥ query): record candidate, go left (`hi = mid - 1`)

### LC 341 — Flatten Nested List Iterator
- Eager flatten in `__init__` using recursive `_flatten` — same pattern as tree DFS
- `_flatten` returns a list, no shared state mutation
- `next()` = index into flat list, `hasNext()` = index < len
- Lazy deque approach: move work to `hasNext()`, expand front element until integer found. Handles `[[]]` correctly.
- **Bug to remember**: `appendleft` in forward loop reverses order — always `reversed()` when pushing to front of deque

### LC 588 — In-Memory File System (conceptual)
- Trie where each node = `{children: dict[str, Node], content: str | None}`
- `content = None` → directory, `content = ""` → empty file, `content = "hello"` → file with data
- Extract `_walk(path) -> Node` helper — reused by mkdir, ls, addContentToFile, readContentFromFile
- `path.split("/")` gives empty string at index 0 — filter with `[p for p in path.split("/") if p]`

## Concepts Covered

### Binary Search Variants
- **Exact match**: exit when `arr[mid] == target`
- **Floor** (largest ≤ target): record candidate, go right
- **Ceiling** (smallest ≥ target): record candidate, go left
- **Rotated array** (LC 153): if `arr[mid] > arr[hi]` → rotation on right → `lo = mid + 1`, else `hi = mid`

### asyncio
- Event loop has two structures: **ready queue** (can run now) and **waiting set** (suspended at await)
- `await` freezes coroutine with locals + instruction pointer, moves to waiting set
- When I/O returns → coroutine moves back to ready queue, resumes from exact line
- `asyncio.Semaphore(N)` — allows N concurrent, blocks (suspends) N+1th caller
- `asyncio.Queue`: `get()` suspends if empty, `task_done()` decrements counter, `join()` waits for counter = 0

### Systems Design Rapid Fire
- **Rate limiter**: deque of timestamps, prune left while `deque[0] < tS - T`, allow if `len < N`
- **Task scheduler with cooldown**: max heap + reinsert map keyed by next available time. Fast-forward if heap empty and nothing ready.
- **Distributed job queue**: states PENDING → IN_PROGRESS → COMPLETED. Visibility timeout + heartbeat for crash recovery.
- **Leaderboard**: Redis ZSET (sorted set), O(log N) update/rank, O(K) top K
- **Autocomplete trie**: store top K completions at each node. Update all nodes on insert path. O(prefix_length) lookup, O(1) return.
- **Critical path / min makespan**: topo sort DAG, `earliest_start = max(earliest_end of predecessors)`. Makespan = longest path. Infinite machines assumed — finite machines is NP-hard (MIP).
